Original draft entry:

## [1.44.0] — 2026-07-31 — Know which files can't be downloaded, and which ones actually arrived

- Files kept in Amazon's Glacier or Deep Archive storage can't be downloaded until you restore them, so they are now left out of a folder download and counted separately, instead of being queued and failing silently. The offer tells you how many were set aside and why. Files in Glacier Instant Retrieval are unaffected — those download normally.
- After a folder download, Bucketer can now check your downloads folder and tell you what actually arrived. It compares each file's name and size, so a half-finished download is reported rather than counted as a success. Anything it can't account for is retried the next time you resume; anything it can't identify with certainty is left alone rather than downloaded again.
- Files whose names the browser changed to avoid a clash — the "(1)" it adds silently — are reported as probably arrived rather than missing, so you aren't sent looking for something already on your disk.
- A finished folder download now stays in the list until you check it or dismiss it. Previously it disappeared the moment it ended, which left no way to find out whether the files ever landed.
- Checking the folder needs a browser that can open a folder picker, currently Chrome and Edge. Elsewhere the option is simply not shown.
